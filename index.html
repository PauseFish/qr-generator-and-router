QR Generator

Maak een QR-code met een vaste URL. De bestemming pas je later aan in links.json — de QR-code blijft hetzelfde.

Alleen kleine letters, cijfers, - en _. Bestaande codes uit links.json worden voorgesteld.

–
–

Wordt automatisch ingevuld op GitHub Pages. Alleen aanpassen als je een eigen domein gebruikt.

Bestemming wijzigen
  1. Open links.json in deze repository op GitHub en klik op het potloodje.
  2. Pas de URL achter je code aan (of voeg een nieuwe regel toe), bijv. "menu": "https://nieuwe-site.nl".
  3. Commit. Binnen ongeveer een minuut stuurt dezelfde QR-code door naar de nieuwe URL.
